连接你的驾驶现场

此页面通过独立服务读取现有程序的输出。

  1. 启动网页服务

    在 26sv 根目录运行 python -B -m UI.server，然后访问 http://127.0.0.1:8765。

  2. 沿用原来的方式运行 MyAutoPilot

    页面自动跟随最新日志。停止写入超过 3 秒时，状态标记为历史快照。网页不会启动或控制自动驾驶。

  3. 查看感知画面

    切换到“实时画面”，保持原程序的 Result 窗口可见、未最小化且未被其他窗口遮挡。画面与日志分别采样，并非严格逐帧同步。

  4. 回看一次运行

    从数据源选择历史日志，用进度条、播放和倍速查看过程。日志只含车道、路径和检测框等数据，不含历史相机画面。

“车道可用 / 换道可用”来自原程序判定，不代表完整的侧后方安全检查。
