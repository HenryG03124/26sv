# 26SV 驾驶感知控制台

在 `26sv` 根目录运行：

```powershell
python -B -m UI.server
```

浏览器打开 <http://127.0.0.1:8765>。默认只监听本机；修改端口可在启动前设置 `$env:UI_PORT = "8766"`。按 `Ctrl+C` 停止服务。

也可以双击本目录的 `start.bat`，然后打开终端中显示的地址。

## 最新日志演示

服务启动后打开 <http://127.0.0.1:8765/?replay=latest&frame=1446&play=1>，自动选择最新日志，从帧序号 1446 开始播放，展示记录中的车道、规划路径和目标检测框。

`replay` 也可指定日志文件名，`frame` 为从 0 开始的帧序号，`play=1` 表示自动播放。回放只展示记录的数据，不会启动自动驾驶。

## 使用

- **自动跟随最新日志**：读取 `MyAutoPilot/logs` 下最新的 JSONL 日志，展示车速、挡位、帧率、转向、油门、刹车、车道、目标与诊断。超过 3 秒没有新记录时显示“历史快照”。速度缺失时显示 `—`。
- **显示主题**：右上角的“深色 / 浅色”按钮切换主题。默认采用黑白界面与白底灰线感知图；深色主题保留深色底、彩色车道、路径和检测框。浏览器会记住选择。
- **感知结构**：显示车道、路径与目标检测框，不绘制车辆模型；可以分别开关三个图层。所有位置仍来自日志的图像坐标，此视图没有相机底图，也不是鸟瞰坐标。
- **实时画面**：读取原程序的 `Result` 窗口。沿用原来的方式启动 MyAutoPilot，并保持该窗口可见、未最小化、未被遮挡。此功能使用项目现有的 `mss`、`numpy`、`opencv-python` 依赖；窗口截图与日志分别采样，不保证严格帧同步。
- **日志回放**：从数据源选择一次历史运行，拖动进度条、播放、暂停或调整倍速。首次选择需要索引文件；后续按偏移读取单帧，不把完整日志载入内存。日志未记录视频，历史回放仅显示结构和状态。回放按记录间隔安排刷新，实际速度受本机读取和浏览器渲染开销影响。
- **导出当前帧**：下载当前记录及其来源信息，便于检查或分享。

页面只读取现有输出，不启动自动驾驶、不发送控制指令、不修改日志。暂停按钮只暂停网页显示。车道及换道可用性沿用原程序判定，不代表完整的侧后方安全检查。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 无构建步骤、无外部 CDN 的网页 |
| `server.py` | 本地静态页面、日志读取和 Result 窗口接口 |
| `start.bat` | 从项目根目录启动服务 |
| `test_server.py` | 日志读取与路径边界测试 |

在根目录运行后端测试：

```powershell
python -B -m unittest UI.test_server
```

所有新增文件都在 `UI` 内。现有 `MyAutoPilot`、`Models` 和训练代码无需修改。
